# balance

Source for https://gajol.github.io/balance/ (Jekyll, Minimal Mistakes theme, GitHub Pages from the `gh-pages` branch).

## Themes

Digital, Psychology, Economics, Cycling.

To put a page under a theme, add `theme: digital` (or `psychology`, `economics`, `cycling`) to its front matter. The theme pages in `_pages/` list everything tagged that way.

## Layout

- `_pages/` standalone pages (CDS and DevOps notes live under `application/`)
- `_books/` book summaries
- `_architecture/` architecture notes
- `_posts/` articles
