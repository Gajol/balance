This is a working demo of the pattern PAT-003: Reference card. It supports the proposal Making legacy content findable in the new site.

Old content does not have to be copied to be found. When someone searches, the new site shows a short card about the old site. It has the site’s name, an owner, a review date and the five most useful documents, each with a direct link. A button carries the same search words to the old site. The old site is plain on purpose, so you can see the contrast.
